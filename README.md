🛡️ ShieldSMS — SMS Spam Detector

ShieldSMS is a machine learning web application that detects whether an SMS message is likely to be Spam or Ham (Normal).

🚀 Live Demo

Try the application:

https://sms-spam-detector-hwss9qxgvctzjvqc.streamlit.app/

✨ Features

- 📩 SMS spam detection
- 🤖 Machine learning-based prediction
- 🧹 Text preprocessing using NLTK
- 🔤 TF-IDF text vectorization
- 📊 Prediction probability visualization
- 🎨 Interactive Streamlit interface
- ☁️ Deployed using Streamlit Community Cloud

🛠️ Technologies Used

- Python
- Streamlit
- Scikit-learn
- NLTK
- NumPy
- TF-IDF
- Machine Learning
